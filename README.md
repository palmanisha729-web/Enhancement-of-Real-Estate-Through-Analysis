Property Consultant Analysis (Excel)
Overview

This project analyzes the performance of a property consultancy business using Microsoft Excel. The analysis focuses on deal types, property categories, locations, commissions, expenses, and client demographics to support data-driven decision-making.

Tools

Microsoft Excel (Pivot Tables, Charts, Filters)

Analysis

Data cleaning and standardization

Location-wise and deal-type analysis

Commission, expense, and profit analysis

Property type and client age-group insights

Outcome

Identified high-performing locations, profitable property types, and key business trends using Excel-based analytics.
